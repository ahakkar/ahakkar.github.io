Agentic analysis 2026

Agent workflows for tender, research and code analysis

Role: Solo project

  • Claude Code
  • Python
  • Typst
  • YAML
  • Municipal ICT tender: 34 documents (180,000 words) condensed into a 25-page cited briefing. Runtime: ~15 minutes.
  • Code review of a 15kLOC web app: 39 findings (4 high severity), 25 doc claims checked against the code. Runtime: ~17 minutes.
  • Research paper: none of a research paper's 14 claims fully held up against its own code and data 🤯.
  • Parallel subagents in separate lanes, steered by a written brief: cheaper models extracted, a stronger one merged.
  • Checked by scripts: all 270 cited quotes matched to their page, sheet or slide, and every code finding cites a file and line.
  • My part: framing questions, choosing the pipeline, approving plans and challenging findings.
  • Lesson: Agentic analysis can save a ton of time and work. Since agents too make mistakes, checking quotes isn't checking claims. Some errors will always slip through!
